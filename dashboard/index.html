TOKEN RADAR

Every protocol that records no token, ranked by what its launch would be worth — and how to farm it.

How the value is worked out

implied value = TVL × category multiple × growth × age × breadth

  • Category multiple — the median market-cap / TVL of the protocols in the same category whose token already trades (3+ peers; otherwise the all-category median), clamped 0.05–1.50. What the market already pays for live TVL is the anchor for a launch.
  • Growth — 1 + 7-day TVL change clamped to −30%…+60%, divided by 200.
  • Age — 1 + 0.15 × years since first listed, capped at 4 years. Longer with no token recorded, more pent-up launch value.
  • Breadth — 1 + 0.02 × chains, capped at 10 chains.

Nothing here is a prediction that a token will be issued, or when. A protocol on this board records no token in the snapshot — that is not proof it has none. Implied values are this radar's own claim, computed from the snapshot's figures alone; no protocol is ranked by name.
